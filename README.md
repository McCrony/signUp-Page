# Sign Up Page

A static sign-up form page built as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## Overview

This project recreates a common registration page layout with:

- A branded left panel with background image and Odin logo
- A right panel containing marketing copy and a sign-up form
- Two-column form inputs for user details
- A call-to-action button and login link

## Built With

- HTML5
- CSS3 (Flexbox)

## Features

- Split-screen layout (`leftPane` and `rightPane`)
- Form fields for:
  - First name
  - Last name
  - Email
  - Phone number
  - Password
  - Confirm password
- Styled visual hierarchy for heading, form area, and actions
- Background image and branding section inspired by TOP design exercise

## Project Structure

- `index.html` - page structure and form markup
- `index.css` - layout and visual styling
- `images/` - logo/background assets used by the page

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.

No build tools or dependencies are required.

## Notes

- This is a front-end practice project and does not submit form data to a backend.
- The form currently uses `action="#"` and is intended for layout/styling practice.
